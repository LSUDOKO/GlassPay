# GlassPay

Scoped, revocable spending cards for AI agents without sharing private keys. Powered by ERC-7710, gasless settlement and total SigNoz observability.

Package manager: bun.

## Commands

- dev: `bun dev`
- typecheck: `bun typecheck`

## Layout

- `docs/`
- `harness-privy/`
- `packages/`
- `probes/`

## Rules

- Never commit secrets or `.env` files.
